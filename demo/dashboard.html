Watcher — Demo Control Panel

Talks directly to the Watcher backend at . Change API_BASE below the script if it's running elsewhere.

1. Simulate an incoming signal

Fires a real log event at POST /ilogs/ingest — iTriage picks it up automatically in the background.







  
2. Incidents & human approval

  
Every incident iTriage created, newest first. Approve/reject only shows while an incident is awaiting_approval — that's the human-confirmation gate, not a formality.

  
  






  
3. Voice room

  
Pick an incident id below to create (or fetch) its room, then join it as a human — the agent joins the same named room via the same call.

  
  
  
  
Only applied when the room is first created -- an existing call ignores this (see get_or_create_call). Language can also be switched live during a call by saying "switch to Tamil" etc.

  

  






  
4. Live incident timeline

  
Renders IncidentCall.structured_state as it actually accumulates — facts, hypotheses, decisions, action items (with resolved owners once the call ends), missing info, conflicts, and chat notes, in the order they were recorded. The coordination health badge and any teal pattern nudge entries are the AI noticing a pattern across everything recorded so far (conflicts piling up, a stale unowned action item, competing theories, or a sharp drop in health) and speaking up on its own — not a reaction to any single thing just said. Auto-refreshes every 3s while a call id is set.
